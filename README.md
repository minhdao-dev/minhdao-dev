## What I focus on

- JWT / OAuth2 authentication flows, token lifecycle management, and security configuration with Spring Security
- Relational database design — schema modeling, Flyway migrations, transaction handling, and query optimization
- Redis-based caching and short-lived state (OTP, session tokens, rate limiting)
- Concurrency control for critical business operations
- Layered, modular architecture using OOP, SOLID, and Design Patterns
- Unit and integration testing with JUnit 5, Mockito, and Testcontainers
- System documentation via architecture diagrams, ERDs, sequence diagrams, and OpenAPI specs
